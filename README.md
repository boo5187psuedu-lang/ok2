# ok2 — أسهم تاسي (TASI Stocks)

عرض بيانات أسهم مؤشر تاسي (سوق الأسهم السعودي).  
Display Saudi stock market (Tadawul All Share Index – TASI) stocks information.

## الاستخدام / Usage

```bash
python tasi_stocks.py
```

## المتطلبات / Requirements

- Python 3.6+

## البيانات / Data

يعرض البرنامج قائمة بأبرز أسهم تاسي مع الرمز والاسم والقطاع.  
للبيانات الحية يرجى زيارة: <https://www.saudiexchange.sa>

The script displays a list of major TASI stocks with symbol, name, and sector.  
For live data visit: <https://www.saudiexchange.sa>
